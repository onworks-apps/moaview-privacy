모아뷰는 개인정보를 수집하지 않습니다. 사용자가 공유 기능으로 보내거나 앱에서 직접 입력한 링크·사진·메모·파일은 기기 안에만 저장됩니다. 모아뷰는 자체 서버를 운영하지 않으며, 개발자는 사용자가 저장한 내용을 볼 수 없습니다. 외부로 나가는 통신은 유튜브 영상의 제목과 미리보기 이미지를 가져오는 것 뿐이며, 자세한 내용은 3항에 있습니다.

01앱이 다루는 정보

모아뷰는 별도의 회원가입이나 로그인이 없습니다. 이름·이메일·전화번호 등을 입력받지 않으며, 사용자가 다른 앱의 공유 기능으로 보내거나 앱에서 직접 입력한 내용만 저장합니다.

항목저장 위치외부 전송
링크 주소 앱 내부 데이터베이스에 문자열로 저장 유튜브 링크에 한해 3항 참조
사진 앱 전용 내부 저장소에 사본 보관, 촬영 시각(EXIF)과 원본 경로를 함께 기록 없음
파일 (PDF·음성) 앱 전용 내부 저장소에 사본 보관, 파일명·크기·재생시간을 함께 기록 없음
메모·문자 내용 공유받은 원문 그대로 앱 내부 데이터베이스에 저장 없음
출처 정보 공유해 준 앱의 이름, 사용자가 직접 적은 메모 없음
사용 기록 항목별 열람 횟수(기기 내 표시용) 없음

위 항목은 모두 사용자 기기 안에서만 처리됩니다. 모아뷰는 광고 식별자, 위치 정보, 연락처, 통화 기록, 문자메시지를 읽지 않습니다.

02보관과 삭제

저장된 내용은 사용자가 직접 삭제하기 전까지 기기에 남아 있습니다. 항목을 삭제하면 먼저 휴지통으로 이동하고, 휴지통에서 30일이 지나면 데이터베이스 기록과 파일 사본이 함께 지워집니다. 휴지통에서 바로 영구 삭제할 수도 있습니다.

설정에서 자동 정리를 켜면, 보관 표시를 하지 않은 항목은 정한 기간(7·30·90일)이 지났을 때 휴지통으로 이동합니다. 이 기능은 기본적으로 꺼져 있으며, 켜더라도 처리는 전부 기기 안에서만 이루어집니다.

설정의 백업에서 저장된 내용을 파일 하나로 내보내고, 나중에 다시 불러올 수 있습니다. 백업 파일은 사용자가 직접 고른 위치에만 저장되며, 개발자를 포함한 어느 곳으로도 전송되지 않습니다. 모아뷰는 구글 드라이브 등 클라우드 자동 백업을 사용하지 않습니다. 백업 파일에는 저장한 내용이 그대로 들어 있으므로 보관과 공유는 사용자가 직접 관리해야 합니다.

앱을 삭제하면 저장된 모든 내용이 함께 사라집니다. 백업 파일을 만들어 두지 않았다면 앱 삭제 후에는 복구할 수 없습니다.

03유튜브 연동

저장된 유튜브 링크를 누르면 모아뷰는 주소를 유튜브 앱에 넘겨주고 역할을 끝냅니다. 영상 재생은 유튜브 앱이 담당하며, 그때부터의 데이터 처리는 해당 서비스의 개인정보처리방침을 따릅니다. 일반 링크도 같은 방식으로 브라우저에 넘깁니다.

목록에서 영상을 알아보기 쉽도록, 모아뷰는 유튜브에 두 차례 요청을 보냅니다. 아래가 전부이며 그 외의 외부 통신은 없습니다.

시점보내는 내용받는 것
링크를 저장할 때 영상 ID만 담은 주소를 youtube.com의 공개 정보 조회 기능(oEmbed)에 전달 영상 제목과 미리보기 이미지 주소
링크를 저장할 때 미리보기 이미지는 유튜브 이미지 서버(i.ytimg.com)에서 받아 기기에 저장합니다. 저장이 끝나기 전에 목록이 화면에 보이거나, 받기에 실패했거나, 백업에서 복원한 항목에 이미지 파일이 없으면 목록을 표시할 때 같은 서버에서 이미지를 불러옵니다. 미리보기 이미지

두 요청 모두 유튜브로만 나가며, 개발자나 다른 곳으로는 가지 않습니다. 다만 이 과정에서 유튜브는 어떤 영상이 언제 저장됐는지, 요청한 기기의 IP 주소가 무엇인지 알 수 있습니다. 특히 첫 번째 요청은 링크를 저장하는 시점에 곧바로 나가므로, 사용자가 앱을 열지 않아도 발생합니다. 이후 처리는 유튜브의 개인정보처리방침을 따릅니다.

내려받은 미리보기 이미지는 앱 전용 내부 저장소에 보관되며, 해당 항목이나 앱을 삭제하면 함께 지워집니다. 모아뷰는 이 요청 기록을 따로 남기지 않습니다.

유튜브 링크 외에는 어떤 통신도 없습니다. 사진, 파일, 메모, 문자 내용, 출처 정보, 그리고 유튜브가 아닌 일반 링크는 기기 밖으로 나가지 않습니다.

유튜브가 아닌 웹 링크는 제목을 알아내려고 해당 사이트에 접속하지 않습니다. 제목은 링크를 공유한 앱이 함께 넘겨준 정보에서만 가져오며, 목록에서 직접 등록한 링크도 같습니다.

04제3자 제공

모아뷰는 어떤 정보도 제3자에게 제공하거나 판매하지 않습니다. 광고 네트워크, 분석 도구, 크래시 리포트 도구를 사용하지 않습니다.

05아동

모아뷰는 아동을 대상으로 하지 않으며, 연령 정보를 포함해 어떤 개인정보도 수집하지 않습니다.

06사용자의 권리

저장된 내용은 전부 사용자 기기 안에 있고 사용자가 직접 관리합니다. 개발자가 보관하는 사본이 없으므로 열람·정정·삭제를 별도로 요청할 대상이 없습니다. 앱 안에서 언제든 삭제하시면 됩니다. 직접 만든 백업 파일은 앱 밖에 있으므로, 필요 없어지면 파일을 따로 지워 주세요.

07방침 변경

내용이 바뀌면 이 페이지를 갱신하고 상단 시행일을 고칩니다. 수집 범위가 달라지는 변경이라면 앱 업데이트 설명을 통해 함께 알립니다.
